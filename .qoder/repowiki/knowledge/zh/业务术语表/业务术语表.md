### 智能体
- 定义：项目中的核心概念，指基于 LangChain + LangGraph 构建的 AI 助手系统，具备情感分析、RAG 智能问答、记忆持久化、质量评估等能力，可集成到钉钉企业应用或提供 Web 聊天界面。
- 别名：AI智能体、钉钉AI智能体助手

### RAG
- 定义：检索增强生成（Retrieval-Augmented Generation），项目的核心问答机制。通过从 ChromaDB 向量库检索相关文档片段，结合 LLM 生成准确回答，解决大模型知识时效性和幻觉问题。
- 别名：检索增强生成、RAG检索

### Checkpointer
- 定义：LangGraph 的状态持久化机制，用于维护多轮对话的上下文连贯性。项目中使用 MemorySaver（进程内）作为短期记忆的 checkpointer，按 thread_id（session_id）管理会话状态。
- 别名：检查点、状态检查器

### Webhook
- 定义：钉钉机器人回调接口，钉钉通过 HTTP POST 请求将用户消息发送到本服务的 /dingtalk/webhook 端点，实现双向消息交互。需要 HMAC-SHA256 签名校验确保请求合法性。
- 别名：回调接口、钉钉回调

### 冒烟测试
- 定义：项目的基础功能验证测试，包含8项测试用例，覆盖核心模块导入、RAG 入库、记忆系统、签名校验等关键功能，确保代码修改后基本功能正常。
- 别名：smoke test、基础测试

### 评估数据集
- 定义：内置的评测样本集合，包含5个覆盖产品功能、技术栈、记忆系统等核心知识点的问题-答案对，每个样本包含 question、expected_answer、reference_context、reference_docs 字段，用于自动化评估智能体回答质量。
- 别名：评测集、评估样本

### 情感分析节点
- 定义：LangGraph 工作流中的第一个处理节点，对用户输入进行情感分类（正面/负面/中性），输出结构化 JSON（label/score/reason），影响后续回复语气策略。LLM 不可用时回退到基于中文情感词典的规则分析。
- 别名：情绪分析、情感分类

### 路由判断节点
- 定义：工作流中的决策节点，根据用户问题和情感分析结果判断是否需要 RAG 检索。使用 LLM 判断 + 关键词兜底策略，区分知识问答和闲聊场景，决定后续处理路径。
- 别名：路由节点、决策节点
