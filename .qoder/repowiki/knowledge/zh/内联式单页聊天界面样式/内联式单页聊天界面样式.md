本仓库的前端样式采用最简化的单文件内联方案：所有 HTML、CSS 与 JavaScript 均集中在 `static/index.html` 一个文件中，未引入任何外部 CSS 框架或构建工具。

**样式体系**
- 使用原生 CSS（无 SCSS/Less/Tailwind），通过 `<style>` 标签内嵌在 HTML head 中。
- 视觉风格为渐变主色调（蓝紫系 `#667eea` → `#764ba2` 背景，头部与发送按钮使用 `#4facfe` → `#00f2fe` 渐变），配合圆角卡片布局与阴影营造现代感。
- 字体栈为 `Microsoft YaHei, PingFang SC, -apple-system, sans-serif`，适配中文显示。
- 响应式策略简单：通过 `max-width: 720px` 限制聊天容器宽度，配合 `width: 100%` 和 `height: 90vh` 自适应屏幕。

**组件结构**
- 页面由 `.chat-container`（主容器）、`.chat-header`（标题栏+操作按钮）、`.chat-body`（消息列表）、`.chat-footer`（输入区）四部分组成，采用 Flexbox 纵向布局。
- 消息气泡通过 `.message.user` / `.message.assistant` / `.message.system` 三类 class 区分角色，用户消息右对齐且使用绿色渐变背景，助手消息左对齐白色气泡。
- 交互元素包括打字指示器（三点弹跳动画 `@keyframes bounce`）、淡入动画（`fadeIn`）以及按钮 hover/禁用态过渡效果。

**约束与约定**
- 样式全部内联，未拆分为独立 CSS 文件或模块，不存在设计令牌（design tokens）或主题变量机制。
- 无 CSS 命名规范文档，类名采用 BEM 风格前缀（如 `.chat-*`, `.message.*`, `.input-row.*`）组织语义。
- 前端逻辑与样式耦合在同一文件中，未使用任何前端框架（React/Vue/Angular）或组件库。

该方案适合轻量级演示用途，但缺乏可维护性与扩展性，不适合大型项目。
