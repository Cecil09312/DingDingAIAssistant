该仓库未包含任何专用的构建脚本、容器化配置或 CI/CD 流水线文件。项目的依赖管理与运行方式如下：

1. **依赖管理**：使用 Python 标准 `requirements.txt` 声明所有依赖，包括 LangChain/LangGraph 智能体框架、FastAPI Web 服务、ChromaDB 向量库、HuggingFace 嵌入模型等。
2. **启动方式**：通过 `python main.py` 直接运行，默认以 Uvicorn 启动 FastAPI 服务（端口 8000），支持 `--repl` 参数进入本地交互式调试模式。
3. **环境配置**：通过环境变量控制 HuggingFace 镜像源（`HF_ENDPOINT`）和离线模式（`HF_HUB_OFFLINE`），其他配置由 `config/settings.py` 中的 Pydantic Settings 管理。
4. **测试**：使用 pytest 框架，测试文件位于 `tests/` 目录，仅包含基础冒烟测试。
5. **评估**：独立的 `evaluation/` 模块提供基于 OpenEvals 和 LangSmith 的自动化评测能力。

由于缺少 Dockerfile、Makefile、CI 配置文件等标准构建产物，该项目目前处于开发原型阶段，尚未建立标准化的构建、打包和部署流程。
