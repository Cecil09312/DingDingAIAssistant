- 节点函数统一签名 `(state: AgentState) -> dict`，仅返回需要覆盖或追加的状态字段，不直接修改 state 对象。
- 对外部依赖（LLM、RAG、记忆、设置）采用函数内延迟 import，避免模块级循环导入并支持按需加载。
- 异常处理采用 try/except 捕获后打印日志并回退到空值或默认文案，保证工作流不因单个节点失败而中断。
- Prompt 模板集中存放在 `prompts.py`，通过 `build_system_prompt` 组装 tone_guidance、long_term_context、rag_context 三个占位符。
- 路由判断采用 LLM 优先 + 关键词兜底的降级策略，当 LLM 调用失败时回退到 ROUTER_KEYWORDS 匹配。
