模块采用入口-评估器-数据集的三层结构：
- `run_eval.py` 是 CLI 入口，通过 `argparse` 暴露 `--no-agent` 和 `--output` 参数，编排完整评估流程：加载数据集 → 调用 `agent.graph.get_compiled_graph()` 执行智能体（可选）→ 批量运行 RAG 评估 → 逐样本运行智能体评估 → 拉取 LangSmith trace 做路径分析 → 汇总输出 JSON 与控制台表格。
- `rag_eval.py` 专注 RAG 四维度评估（retrieval_relevance、groundedness、helpfulness、answer_relevance），通过 `_make_evaluator` 统一用 `openevals.llm.create_llm_as_judge` + 预置 prompt 构建评判器，`evaluate_batch` 提供批量接口。
- `agent_eval.py` 专注智能体三维度评估（correctness、hallucination、plan_adherence），并提供 `fetch_recent_traces` / `analyze_trace_paths` 两个 LangSmith 集成函数，用于基于实际运行 trace 的路径合理性统计。
- `datasets.py` 定义 `EvalSample` TypedDict 并内嵌 `RAG_EVAL_DATASET`，由 `get_dataset()` 暴露。
- 依赖方向单向：入口 → rag_eval / agent_eval → datasets；LLM 实例与配置均通过 `config.settings.get_settings()` 懒加载获取，避免循环导入。
