钉钉AI智能体助手产品说明文档

一、产品概述
钉钉AI智能体助手是一个基于 LangChain 和 LangGraph 构建的企业级智能对话助手，专为钉钉平台设计。它集成了情感分析、智能问答、RAG 检索增强生成、短期与长期记忆、智能体评估等核心能力，能够为钉钉用户提供智能化、个性化的问答与辅助服务。

二、核心技术栈
1. LangChain：用于构建应用逻辑与 LLM 调用链路。
2. LangGraph：用于实现智能体的状态图（StateGraph）工作流编排，支持多步骤推理与决策路由。
3. 千问大模型：通过 OpenAI 兼容接口调用，作为底层生成与推理模型。
4. ChromaDB：用于向量存储与语义检索。
5. HuggingFace bge-small-zh-v1.5：本地 Embedding 模型，中文检索效果好。
6. SQLite：用于长期记忆的持久化存储（Python 内置，无需外部服务）。
7. OpenEvals 与 LangSmith：用于智能体评估与质量评测。

三、核心功能
1. 情感分析：对用户输入消息进行正面、负面、中性分类，并将情感分析结果作为上下文信息融入智能体响应策略中，影响回复的语气与风格。负面情绪时采用共情安抚语气，正面情绪时采用热情积极语气，中性时保持客观专业。

2. 智能问答与 RAG 系统：
   - 实现基于 RAG（检索增强生成）的智能问答功能。
   - 包含文档加载、文本切分、向量化存储、语义检索与生成式回答的完整 pipeline。
   - 文档加载支持 txt、md 等格式，使用 RecursiveCharacterTextSplitter 进行切分。
   - 向量存储使用 ChromaDB，Embedding 使用本地 HuggingFace 模型。
   - RAG 质量评估包含检索相关性评估与生成质量评估（答案忠实度、相关性打分）。

3. 记忆系统：
   - 短期记忆：在对话过程中维护当前会话的上下文与交互历史，支持多轮对话的上下文连贯性。基于 LangGraph checkpointer 实现，按 thread_id（即 session_id）维护。
   - 长期记忆：使用 SQLite 作为持久化存储后端，保存跨会话的用户偏好、关键信息摘要及历史交互摘要，实现长期个性化服务。

4. 智能体评估：
   - 使用 LangSmith 和 OpenEvals 构建智能体的评估体系。
   - 支持对智能体回答质量、推理路径合理性、工具调用准确性等维度进行系统化评测。
   - 二者结合使用以互补评估能力。

四、工作流编排
智能体采用 LangGraph StateGraph 编排，工作流程为：情感分析 → 路由判断 → 加载长期记忆 → 条件分流（RAG 检索或直接生成）→ 生成回答 → 更新长期记忆 → 结束。

五、钉钉集成
提供与钉钉平台对接的接口，包括 Webhook 接收与消息回调。支持签名校验（HMAC-SHA256），确保请求来源合法。智能体接收钉钉消息后生成智能回复并通过钉钉消息接口返回。
